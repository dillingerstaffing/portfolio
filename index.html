PROJECT 01 / FROM-SCRATCH KERNEL

RISC-V bare-metal scheduler

A freestanding 64-bit RISC-V kernel for QEMU’s virt machine. It boots directly into M-mode, drives an ns16550a UART over MMIO, and interleaves three tasks with real assembly context switches.

  • BOOTCustom entry, stack setup, BSS clear
  • MEMORYLinked at 0x80000000
  • SCHEDPrivate 4 KiB task stacks, round robin
  • BUILD-ffreestanding, -nostdlib, -nostartfiles

PROJECT 02 / KERNEL EXTENSION

xv6 syscall accounting

A focused extension to MIT’s xv6 RISC-V kernel. getscount(n) reports how many times the calling process invoked syscall n, wired from user-space stub through dispatcher to per-process kernel state.

  • HOOKSingle syscall dispatch funnel
  • STATEPer-process uint64 counter table
  • GUARDCompile-time dispatch-table size check
  • TESTCounts, bounds, and fork lifecycle
